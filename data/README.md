# Dados brutos — State of Data Brazil

Os arquivos CSV originais não são versionados neste repositório (tamanho e licença do Kaggle).

## Como obter

1. Acesse o [State of Data Brazil no Kaggle](https://www.kaggle.com/datahackers/datasets).
2. Baixe as 3 edições usadas neste projeto:
   - **2023-2024** (5.293 respostas)
   - **2024-2025** (5.217 respostas)
   - **2025-2026** (3.495 respostas)
3. Salve os 3 CSVs nesta pasta (`data/`).

O de-para de nomes de coluna entre as edições está documentado em `../docs/mapeamento_schema.md`.
